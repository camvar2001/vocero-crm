# Marca isIA — recursos oficiales

Fuente: paquete del propietario «Branding oficial red neuronal», guía v1.1.
`logo-light.svg` e `icon.svg` son copias exactas. `logo-dark.svg` conserva el SVG oficial sobre-oscuro y extrae exclusivamente el rectángulo externo id=fondo de presentación, dejando intacto el grupo logo-isIA. Sin recolor, recortes del logo, deformaciones, sombras ni efectos.

Cian #007A80, grafito #14181F, cobre #C9622E, cielo #ECF9F9, oscuro #0D1016, cian claro #67BDC1. Logo completo >=96px e icono de UI >=32px. Recursos locales, sin iCloud/CDN en runtime.
